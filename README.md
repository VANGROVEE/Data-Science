# 🌿 VANGROVE - Data Wrangling & EDA

Branch ini berisi pipeline pembersihan data dan *Exploratory Data Analysis* (EDA) untuk dataset VANGROVE.

## 🚀 Cara Menjalankan Notebook dengan Cepat
Agar tidak perlu memproses ulang gambar dari Google Drive (yang memakan waktu sangat lama), kita menggunakan jalur pintas dengan membaca file CSV hasil ekstraksi:

1. Download file `cleaned_dataset.csv` dari branch ini ke laptop kamu.
2. Buka file `data_wrangling.ipynb` di Google Colab.
3. Upload file `cleaned_dataset.csv` tadi ke dalam tab *Files* di Google Colab kamu (ikon folder di sebelah kiri).
4. Langsung lakukan **Run All** pada notebook.

Notebook akan langsung memproses visualisasi grafik tanpa perlu mendownload gambar fisik!
